rclone Drive Access

This is a private, single-user OAuth client used by its owner to access their own Google Drive with rclone (an open-source command-line file sync tool) on their personal computer. It is not offered to the public.

Privacy Policy

The app accesses Google Drive files only on behalf of the account owner who authorizes it, solely to upload, download, list and delete the owner's own files at the owner's request.

  • No data is collected, stored or processed on any server operated by this app. Files and OAuth tokens stay on the owner's local machine.
  • No Google user data is shared with, sold to, or transferred to any third party.
  • Data is not used for advertising, analytics or model training.
  • Access can be revoked at any time at myaccount.google.com/connections.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
